            METHOD & BOUNDARIES

            让每一步都能被看见

            这是一个受控的科研分析工具，而不是会“自动写出看起来很像结论”的聊天框。

            01 / CONTROLLED TOOLS

            只有注册过的工具能运行

            模型只能选择工具、字段与参数；工具名、列名和取值都会在执行前被校验。模型生成的 Shell、Python 或 JavaScript 不会被运行。

            profile_datasetmissingness_reportgroup_summarygroup_comparisonone_way_anovacorrelation_analysis
            02 / DATA BOUNDARY

            原始数据留在本机

            CSV 只进入当前 Node.js 进程的内存。若启用模型，只发送研究问题、字段结构、缺失率和聚合后的字段概况，不发送原始行。

            仅支持公开、非涉密 CSV；不接入账号、数据库或云端文件存储。
            03 / EVIDENCE CHAIN

            结论必须回到一次工具调用

            每个关键发现都带证据 ID。运行记录保留工具名、字段、参数、耗时和真实输出；图表与报告数字由同一份工具结果生成。

            EVIDENCE group_summary → one_way_anova → call_002
            OPEN DATA / DEMO SOURCE

            Iris，而且来源可查

            内置示例使用 UCI Machine Learning Repository 的 Iris 数据集。我们只添加英文列名并映射类别标签，不修改测量值； 每个数据集都会记录 SHA-256，报告会显示来源、许可和已知数据注意事项。

            研数搭子怎么工作

            01检查数据

            读取字段、缺失率、重复行和基础分布。

            02理解与规划

            判断问题适合分组比较还是相关分析；无 Key 时用本地规则，配置后由 DeepSeek 通过官方 API 的 tool calls 选择工具。

            03执行与复核

            调用受控统计工具；独立复算分组均值和相关系数，再生成报告。

            本版支持的边界

            • 一个分类字段 × 一个数值字段的组间差异（两组 Welch t，三组及以上 ANOVA）
            • 2–8 个数值字段的 Pearson / Spearman 相关
            • CSV、公开数据、单机内存；不支持 PDF 论文解析、网页搜索、登录、数据库、因果推断或预测建模
            演示模式

            后端没有有效 DEEPSEEK_API_KEY（包括仍是模板占位值）时启用。不调用模型，使用本地确定性规则规划；统计工具真实执行，界面会明确标注。

            DeepSeek 工具调用

            在后端 .env 配置 DEEPSEEK_API_KEY 后启用。只连接 DeepSeek 官方 API；通过原生 tool calls 选择受控分析工具，不生成统计数字。

            仅连接 https://api.deepseek.com，不配置其他厂商或国外模型端点。DeepSeek 不接收原始 CSV 行；只接收研究问题、字段结构和聚合概况。模型返回的工具参数必须通过后端注册表校验后才会执行。
